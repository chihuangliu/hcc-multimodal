# Report Contents

## Background Section

You should summarise the essential material related to the subject of the project, for example a review of relevant academic literature. This material can be incorporated into the project final report.

> **Important:** Referencing should use the **Vancouver format**.

---

## Progress Section

You should also include a separate section on progress that describes:

* The activities and accomplishments of the project to date.
* Any problems or obstacles that might have cropped up and how those problems or obstacles are being dealt with.
* Plans for the next phases of the project.

---

## Section Headings

There are no mandated section headings for this report. The best format will vary from project to project. A format that works well for many types of project is:

* **Title Page**
* **Table of Contents**
* **Chapter 1 - Introduction**
* Introduce the project and the problem.
* Provide some context for a reader who is not an expert in this area.


* **Chapter 2 - Literature Review**
* Describe the work that has already been completed that is relevant to the problem you are addressing.
* *Note:* Some projects may need an additional section covering notation, key theories or other such technical information.


* **Chapter 3 - Technical Achievements/Experimentation**
* If you have completed any early experiments or tested out different methods, you can briefly discuss them in this chapter.
* *Note:* This chapter will not be relevant for all projects and you might not have reached this stage yet.


* **Chapter 4 - Project Plan**
* Discuss the plan for the remainder of the project. Include a timeline.
* It is useful to define what success in your project will look like. You might be able to compare your system against existing systems.
* **Ethical Review:** If your ethical review has identified that you will need to get Imperial ethical approval for your project (e.g. you are conducting research using medical data), please flag this here.


* **References**
* Use **Vancouver Format**.


* **Appendices**
* Unlikely to be needed for this short document, but you can include supplementary information if necessary.



> **Note:** There is no need to include an Abstract or an Acknowledgements page within this document. Some reports may use different chapter titles. That is fine.

---

## Report Format and Length

* **Template:** Please see the main course folder for instructions and a template which apply to both the Background Report and the Final Report.
* **Page Limit:** The **maximum length** for the Background and Progress report is **20 pages**, plus appendices (if necessary).
* **Inclusions:** That page count includes all pages other than the appendices, including title pages and references.
* **Typical Length:** A typical length for these reports is **10 to 20 pages**.
